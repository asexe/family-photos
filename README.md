# 家庭相册 · Family Photos

> 一个纯本地运行的 Windows 照片 / 视频管理软件。家人各建账号、各自指定照片文件夹，
> 软件就地索引（**不复制、不移动原文件**），自动按人整理、检测完全相同的文件提醒删除、
> 读取拍摄时间与 GPS，并提供苹果相册风格的时间轴、地图和深色大图浏览窗口。

**版本 v0.9** · Python + PySide6 (Qt6) · 数据 100% 留在本机，无任何联网上传

---

## ✨ 功能

### 多用户与数据源
- 每位家人一个账号（可配颜色标签），一个账号可挂**多个照片文件夹**
- 递归扫描文件夹，**原地索引**：原文件位置、文件名、目录结构一概不动
- **自动入库**：监控数据源文件夹，放入新照片/视频后自动扫描（可在设置里关闭）
- **启动自动扫描** + 手动「重新扫描」；增量判断「路径+大小+修改时间」，秒级完成
- 扫描后自动清理磁盘上已删除的失效记录（可关闭）
- 多线程处理（哈希 / 解码 / 缩略图并行）

### 照片与视频
- 图片：JPG / PNG / **HEIC（苹果）** / HEIF / GIF / WEBP / BMP / TIFF
- 视频：MOV / MP4 / M4V / AVI / MKV / WMV / WEBM / 3GP
- 视频自动抓取首帧作为缩略图，时间轴里带 ▶ 播放角标
- 大图浏览窗口内嵌播放器：播放/暂停、进度条拖动、音量、空格暂停、←→ 切换

### 重复文件检测（只提醒，不自动删）
- 基于文件内容 SHA-256 **精确去重**，文件名不同也算重复
- 重复项自动归组，给出「建议保留」：有 GPS > 分辨率高 > 文件大
- 确认后其余移入**回收站**，可随时恢复

### 回收站（删除可恢复）
- 删除的照片/视频进入「回收站…」：缩略图预览、原位置、删除时间
- 支持 **恢复选中** / **彻底删除** / **清空回收站**；恢复后自动重扫重新入库

### 时间与地理定位
- 读取 EXIF `DateTimeOriginal` + 原时区偏移（无 EXIF 时回退文件时间并标注）
- 读取 EXIF GPS 经纬度/海拔；iPhone 视频从 QuickTime 元数据（ISO6709）解析坐标
- **离线地点反查**：内置 5900 座城市（含 315 个中文地级市，无需联网），
  GPS 自动转成「省·市」（如 `福建省·厦门市`），支持按**地点筛选**
- 统一存 UTC 基准时间 + 时区偏移，跨时区排序不乱

### 苹果相册风格界面
- 无边框窗口：**圆角 + 半透明**（Windows 11 自动叠加 Mica 背景），
  右上角控制键「缩小（黄）/ 放大（绿）/ 关闭（红）」
- **时间轴照片墙**：按年月分组、组间分割线标题，右侧**年份/月份刻度尺**可切换
  「年 / 年+月」两档缩放、点击跳转，当前浏览月份高亮跟随滚动
- **地图主页**：世界地图（国家/省份边界），照片按 GPS 聚合成缩略图圆点，
  数量越多圆点越大，缩放到细节自动拆分，家人复选框按人筛选，支持地图/卫星切换
- 家人树形分类：`所有照片 / 视频 / 收藏 / 有地理定位 / 无地理定位 / 重复照片`
- 深色大图浏览窗口（缩放/拖动/左右切换/收藏/删除）

## 🚀 安装与运行

### 方式一：免安装 exe（给家人用，推荐）

下载/构建后直接双击 `家庭相册.exe` 即可，无需安装 Python：

```bash
python -m pip install pyinstaller
python tools/build_exe.py      # 产物在 dist/家庭相册/
```

整个 `dist/家庭相册/` 目录可拷到任意 Windows 电脑；数据（数据库/缩略图/回收站）
保存在 exe 同级的 `data` 目录，备份或换机时一起拷走即可。

### 方式二：源码运行（开发用）

环境要求：Windows 10/11，Python 3.10+（推荐 3.12）

```bash
git clone https://github.com/asexe/family-photos.git
cd family-photos
python -m pip install -r requirements.txt
python main.py
```

首次使用：

1. 点左下角 **用户管理…** → 添加家人（如：爸爸、妈妈）
2. 点左下角 **数据来源…** → 选择某位家人 → **添加文件夹…** → 选择照片目录
3. 弹窗询问「是否立即扫描」→ 选「是」，等待扫描完成（每千张约 1 分钟，视硬盘而定）

> 之后往这些文件夹里再放照片/视频，软件会**自动发现并入库**（可在「设置…」中关闭）。
> 扫描期间照片墙会自动刷新，可以边扫边看。

## 🗂 项目结构

```
photo-manager/
├── main.py                  # 入口
├── requirements.txt
├── app/
│   ├── db.py                # SQLite 访问层（含迁移、回收站表）
│   ├── scanner.py           # 扫描 / 元数据 / 去重分组 / 失效清理（多线程）
│   ├── exif_reader.py       # 图片 EXIF：时间 / GPS / 方向 / 相机
│   ├── thumbs.py            # 缩略图与预览图（含视频首帧、QuickTime 元数据）
│   ├── places.py            # 离线地点反查（GPS → 省·市）
│   ├── watcher.py           # 数据源文件夹监控（防抖后自动扫描）
│   ├── settings.py          # 设置存储（data/settings.json）
│   ├── hashing.py           # SHA-256
│   ├── dedup.py             # 重复组处理 + 回收站（删除/恢复/彻底删除）
│   ├── map_server.py        # 地图页本地 HTTP 服务（127.0.0.1 随机端口）
│   ├── data/cities.txt      # 内置离线城市库（5900 座）
│   ├── map/                 # Leaflet 地图页 + 本地图标库
│   └── ui/                  # 界面
│       ├── main_window.py   # 主窗口（侧边栏 / 筛选栏 / 时间轴 / 自动扫描）
│       ├── timeline_wall.py # 时间轴照片墙（虚拟化绘制 + 年月刻度尺）
│       ├── viewer_window.py # 大图浏览 / 视频播放窗口
│       ├── dialogs.py       # 用户 / 数据源 / 重复照片 / 回收站 / 设置
│       ├── widgets.py       # 无边框圆角窗口、标题栏、动画下拉框
│       ├── icons.py         # SVG 图标着色加载
│       └── style.py         # 主题与 QSS
├── tools/                   # 命令行工具（扫描 / 自检 / 打包 / 生成地点库）
└── docs/                    # 设计文档与各版本发布说明
```

运行数据（数据库 `photos.db`、缩略图缓存、回收站）统一放在 `data/` 目录，已在 `.gitignore` 中排除。

## 🧰 命令行工具

```bash
# 直接扫描一个文件夹（自动创建用户与数据源）
python tools/scan_cli.py "D:\照片" --user 爸爸

# 对某个文件夹做一次自检（哈希 / EXIF / GPS / 缩略图）
python tools/selftest.py "D:\照片"

# 打包成免安装 exe（产物在 dist/家庭相册/）
python tools/build_exe.py

# 重新生成离线城市库（需要联网，约 2.5 MB 下载）
python tools/build_places.py
```

## 🛠 技术要点

| 关注点 | 做法 |
|--------|------|
| HEIC 解码 | `pillow-heif` 注册 Pillow opener，图片/缩略图/EXIF 走同一套代码 |
| 视频首帧 | OpenCV 抓帧后转 JPEG，与照片共用缩略图缓存 |
| 苹果视频元数据 | 扫描文件首尾 8MB，正则匹配 ISO6709 坐标与 `creationdate` |
| 离线地点反查 | GeoNames 城市库 + 中文省市表 → 紧凑城市表，1° 网格 + 半正矢距离就近匹配 |
| 自动入库 | `QFileSystemWatcher` 递归监听数据源目录，变化后防抖 4 秒再增量扫描 |
| 上万张不卡 | 时间轴为**虚拟化自绘**（只画可见区域），缩略图走 `QPixmapCache` |
| 半透明圆角窗口 | 无边框 + `WA_TranslucentBackground` + 圆角蒙版，Win11 尝试 Mica |
| 下拉弹层稳定 | 完全自绘下拉框 + 弹层强制锚定在框正下方，规避 Qt 弹层定位问题 |
| 删除安全 | 一律移入 `data/trash/` 并在数据库登记，可预览/恢复/彻底删除 |
