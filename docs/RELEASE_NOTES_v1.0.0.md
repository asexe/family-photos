# 家庭相册 v1.0.0

第一个功能完整的正式版：**相似照片检测**与**日历视图**上线，
配合自动入库、地点筛选、回收站与免安装 exe，家庭本地照片汇总与筛选的闭环完成。

## ✨ 本次新增

### 1. 相似照片检测（连拍 / 微信压缩版）
- 新增感知哈希（**dHash 64 位**）：缩放到 9×8 灰度图比较相邻像素亮度，
  对缩放、二次压缩、轻微裁剪不敏感，只用 Pillow，无额外依赖
- 扫描时自动为每张照片/视频首帧计算哈希；已有照片首次启动后台补算
  （实测 5936 张约 47 秒，之后增量）
- **星型聚类**：以种子为中心成组，避免了「A≈B、B≈C 就把 A 和 C 并在一起」的链式误合并
  （实测：5913 张参与比对仅 0.5 秒，阈值 4 时得到 226 组 / 598 张）
- 与「完全相同」（SHA-256）**完全独立**：重复照片走精确队列，相似照片走相似队列
- 新增「相似照片」分类 + 处理窗口：并排预览、建议保留（有 GPS > 分辨率高 > 文件大）、
  逐组确认删除（进回收站）、**「忽略此组」**（记住判断，重算后不再提示）
- 灵敏度可调（设置…）：严格（3）/ 标准（4）/ 宽松（6）

### 2. 日历视图
- 侧边栏新增「**日历**」：月历格子里直接显示**封面缩略图 + 当天照片数量**
- 自绘网格（性能好、样式统一）：有照片的日期显示封面，无照片的日期置灰不可点
- 月份左右切换 + 「今天」按钮；顶部显示「本月 N 张 · 有照片 M 天」
- **点击某天 → 立刻筛选出当天的照片**（实测 2021-07-20 → 106 张）

### 3. 其它
- 扫描后有新照片时，自动在后台重算相似组（不阻塞界面）
- 统计信息新增「相似待确认」组数
- 版本号显示在窗口标题（家庭相册 v1.0.0）

## 🚀 升级说明

从 v0.9 升级：替换程序文件即可，数据库自动补列（`phash`、`kind`、`similar_ignored` 表）。
首次启动会在后台为已有照片补算感知哈希（约 6 千张 47 秒），期间界面可正常使用。

## 🧰 完整功能一览

| 能力 | 说明 |
|------|------|
| 多人多数据源 | 家人各一个账号（颜色标签），一人可挂多个文件夹，原地索引不动原文件 |
| 自动入库 | 监控文件夹 + 启动扫描 + 手动重扫，增量判断，秒级完成 |
| 照片/视频 | JPG/PNG/HEIC/GIF/WEBP… 与 MOV/MP4…（首帧缩略图、内嵌播放器） |
| 精确去重 | SHA-256，相同内容归组，建议保留，删除进回收站 |
| **相似检测** | **dHash 星型聚类，连拍与压缩版，独立队列，可忽略误报** |
| 时间与地点 | EXIF/QuickTime 拍摄时间与 GPS；离线反查「省·市」；地点筛选 |
| 浏览 | 时间轴照片墙（年月分割线 + 刻度尺）、**日历视图**、地图（聚类圆点 + 家人筛选）、深色大图/视频窗口 |
| 安全 | 回收站可恢复、失效记录自动清理、数据全在本机 |
| 分发 | 免安装 exe（`tools/build_exe.py`），数据在 exe 同级 data 目录 |

## ⚠️ 已知限制

- 相似检测基于感知哈希，**截图类内容可能误报**（界面相似的截图会成组），
  已提供「忽略此组」；调严灵敏度也可减少
- 地点为离线最近地级市近似，非精确行政区划
- 地图底图依赖在线瓦片，断网时仅显示点位
