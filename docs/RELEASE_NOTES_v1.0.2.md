# 家庭相册 v1.0.2

## 🔧 调整：日历改为可选（默认关闭）

日历视图与「时间轴照片墙 + 年份/月份刻度尺」的功能有重叠，实际使用中价值有限，
因此不再默认占用侧边栏位置：

- **侧边栏默认不再显示「日历」入口**
- 需要时可在「**设置…**」里勾选「在左侧显示『日历』视图」随时打开（立即生效，无需重启）
- 日历页改为**惰性加载**：不显示时不创建、不查询，启动更轻快
- 关闭日历时若正停留在日历/某一天，会自动切回「全部照片」

功能代码与数据（月历封面、按天筛选）全部保留，未做删减。

## 升级说明

替换程序文件即可，无需改动数据库。已有设置会保留；`show_calendar` 默认 `false`。
