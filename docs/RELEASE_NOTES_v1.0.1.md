# 家庭相册 v1.0.1

## 🐞 修复：地图页进入时一片空白

**现象**：软件启动进入地图页时，底图不显示（白屏），且「地图 / 卫星」两个按钮都没有高亮。

**原因**：地图默认使用高德在线瓦片，瓦片加载失败时会自动回退到 OpenStreetMap，
但（1）OSM 在国内网络同样常被拦截，（2）回退后界面把「地图」按钮的选中态也一并取消了，
于是既没有底图、也没有任何按钮处于选中状态。

**修复内容**：
1. **内置离线轮廓底图**：打包世界国界（180 个）与中国省界（35 个）矢量数据（共 534 KB），
   断网也能看到地图轮廓与省市边界，照片点位照常显示
2. **新增「离线」图层按钮**，三层可选：地图（高德）/ 卫星（高德影像）/ 离线（内置轮廓）
3. **按钮状态始终一致**：OpenStreetMap 作为高德的备用街道图，仍归在「地图」按钮下，
   不会再出现「三个按钮都没选中」的情况
4. **启动即探测网络**：4 秒内探测高德瓦片是否可用，不可用则直接切到离线底图，
   并在右上角提示「网络不可用，已切换到内置离线轮廓底图」
5. 地图容器底色由纯白改为浅灰（#EDEFF2），任何情况下都不会是刺眼的白色
