# 家庭相册 v0.8.0

首个公开版本：一个**纯本地运行**的 Windows 照片 / 视频管理软件。
家人各建账号、各自指定文件夹，软件就地索引（不复制不移动原文件），
自动按人整理、检测完全相同文件提醒删除，并提供苹果相册风格的时间轴与地图。

## ✨ 核心功能

**多用户与数据源**
- 每位家人一个账号（可选颜色标签），一人可挂多个文件夹
- 递归扫描 + **增量扫描**（按路径/大小/修改时间判断），二次扫描秒级完成
- 多线程处理哈希、解码、缩略图

**照片与视频**
- 图片：JPG / PNG / HEIC（苹果）/ HEIF / GIF / WEBP / BMP / TIFF
- 视频：MOV / MP4 / M4V / AVI / MKV / WMV / WEBM / 3GP，自动抓首帧做缩略图
- 时间轴里视频带 ▶ 播放角标；大图窗口内嵌播放器（进度条 / 音量 / 空格暂停）

**重复检测（只提醒，不自动删）**
- 文件内容 SHA-256 精确比对，文件名不同也算重复
- 自动建议保留（有 GPS > 分辨率高 > 文件大），其余移入内置回收站，可恢复

**时间与地理定位**
- EXIF 拍摄时间 + 原时区偏移；GPS 经纬度与海拔
- iPhone 视频自动解析 QuickTime 元数据（ISO6709）中的真实录制时间与坐标

**苹果相册风格界面**
- 无边框**圆角半透明**窗口（Windows 11 自动叠加 Mica），右上角「缩小黄 / 放大绿 / 关闭红」
- **时间轴照片墙**：年月分组分割线 + 右侧年份/月份刻度尺（「年 / 年+月」两档缩放、点击跳转、当前月份高亮跟随）
- **地图主页**：世界地图（国家/省份边界），照片聚合成缩略图圆点，数量越多越大，
  放自动拆分到细节，家人复选框按人筛选，地图/卫星切换
- 家人树分类：`所有照片 / 视频 / 收藏 / 有地理定位 / 无地理定位 / 重复照片`
- 深色大图浏览窗口：缩放、拖动、←→ 切换、收藏、删除
- 全面图标体系（Element 风格线性图标）、下拉弹层淡入与圆角、平滑滚动动画

## 🚀 安装

```bash
git clone https://github.com/lc13500024356/family-photos.git
cd family-photos
python -m pip install -r requirements.txt
python main.py
```

环境：Windows 10/11 + Python 3.10+（推荐 3.12）

首次使用：左下角「用户管理…」添加家人 → 「数据来源…」给家人添加照片文件夹 →
弹窗选「立即扫描」。

## 🧰 命令行工具

```bash
python tools/scan_cli.py "D:\照片" --user 爸爸   # 直接扫描文件夹
python tools/selftest.py "D:\照片"              # 抽样自检（哈希/EXIF/GPS/缩略图）
```

## ⚠️ 已知限制

- 视频缩略图为**首帧**，非智能封面
- 近似重复（连拍 / 二次压缩）暂未检测，当前只做精确去重（v0.9 计划 pHash）
- 尚未打包为单文件 `.exe`，需 Python 环境运行（v1.0 计划）
- 地图底图使用高德公开瓦片，仅作个人本地区位参考
