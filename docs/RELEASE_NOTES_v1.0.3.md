# 家庭相册 v1.0.3

## 🐞 修复：地图页完全卡死（按钮点不动、中间空白、无法缩放）

**现象**：地图页三个图层按钮（地图/卫星/离线）点了没反应，地图中间一片空白，也无法缩放。

**根因**：`leaflet.markercluster` 在把照片聚合层加入地图时会检查地图的最大缩放级别：

```js
if (!isFinite(this._map.getMaxZoom())) throw "Map has no maxZoom specified";
```

v1.0.1 我把启动流程改成「先探测网络连通性、探测完成后再挂底图」，
于是照片聚合层挂载时**地图上还没有任何瓦片图层**，`getMaxZoom()` 返回 `Infinity` 直接抛异常——
照片层没加上，后续的定位、渲染全部中断，界面就成了死图。

**修复**：
1. 地图创建时显式指定 `maxZoom: 19`，无论如何 `getMaxZoom()` 都是有限值
2. **立即挂载默认底图**（不再等探测结果），网络探测只用于「失败后回退」
3. 保留 v1.0.1 的改进：底图失败自动回退 OSM → 再回退内置离线轮廓，按钮状态始终一致
