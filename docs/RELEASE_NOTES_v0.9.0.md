# 家庭相册 v0.9.0

面向**单机家庭使用**的一次体验升级：照片放进文件夹就自动入库，能按地点筛选，
删除可恢复，并且可以直接打包成免安装 exe 给家人双击使用。

## ✨ 本次新增

### 1. 自动入库（不用再手动扫描）
- **自动监控数据源文件夹**：往文件夹里拷照片/视频后，软件自动发现并增量扫描入库
  （变化后等待约 4 秒安静期再扫描，拷贝大文件时不会反复触发）
- **启动时自动扫描**：打开软件即自动补齐上次之后新增的文件
- 新增「设置…」：可分别开关自动监控、启动扫描、失效清理

### 2. 地点识别与筛选
- 内置 **离线世界城市库**（约 5900 座城市，含 315 个中文地级市，239 KB，无需联网）
- 照片与视频的 GPS 自动反查为「**省·市**」（如 `福建省·厦门市`、`广东省·广州市`），
  村镇照片会自动归到最近的地级市
- 顶部工具栏新增 **「全部地点」筛选**，只列出库里实际出现过的地点并显示数量
- 大图浏览窗口显示地点；地图圆点悬停也会显示地点

### 3. 回收站（删除可恢复）
- 删除的照片/视频统一进入「**回收站…**」：缩略图预览、原位置、删除时间
- 支持 **恢复选中**（文件移回原位置）/ **彻底删除** / **清空回收站**
- 恢复后自动重扫，照片重新回到时间轴

### 4. 失效记录自动清理
- 磁盘上已删除的文件，扫描时自动从索引中移除（可在设置里关闭）
- 不会再出现「点开提示无法加载」的僵尸记录

### 5. 免安装 exe 打包
- 新增 `tools/build_exe.py`，一条命令生成免安装版本：
  ```bash
  python -m pip install pyinstaller
  python tools/build_exe.py
  ```
- 产物 `dist/家庭相册/` 可整体拷到任意 Windows 电脑，双击 `家庭相册.exe` 即可运行
- 数据（数据库/缩略图/回收站）保存在 exe 同级的 `data` 目录，便于备份与迁移

### 6. 修复
- **修复数据目录路径错误**：早期版本把数据写到了项目上一级目录，
  现已统一到程序目录下的 `data/`，并提供一次性迁移脚本
- 修复视频播放/时间轴渲染相关的若干问题

## 🚀 升级说明

从 v0.8 升级：直接替换程序文件即可，数据库会自动补列（`place` 等）；
首次启动会为已有 GPS 的照片回填地点（约 3000 张耗时 0.4 秒）。

## ⚠️ 已知限制

- 地点为**离线最近城市**近似（无网络时可用的折中方案），非精确行政区划
- 近似重复（连拍/压缩版本）仍未检测，当前只做精确去重
- 地图底图依赖在线瓦片，断网时仅显示点位与轮廓
